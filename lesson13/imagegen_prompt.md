# Lesson 13 ImageGen prompt

Purpose: create a beginner teaching image that presents the Megakernel experiment roadmap as a sequence of evidence gates with explicit stop branches, so a weak idea is rejected before it expands to a full model.

Use case: scientific-educational

Asset type: Lesson 13 hero infographic for a Chinese GPU course

## 16:9 visual requirements

- Exact canvas: 1672×941 pixels, landscape 16:9.
- Dark navy blueprint background, cyan main route, lime passed gates, amber unmeasured stages, orange-red stop branches.
- Polished flat vector-like roadmap, restrained glow, five large stages, clear arrows, generous whitespace, large Simplified Chinese typography.
- Stop branches must look like valid research outcomes, not failures or trash.
- No photorealism, people, logos, watermark, benchmark graph, or performance numbers.

## Text (verbatim)

Main title:

“先用小实验排除错路”

Short labels; render only these labels and no additional prose:

- “冻结基线”
- “Same-body 判决”
- “单层数据流”
- “逐级扩大”
- “停止条件”

## Core composition

Draw one ascending five-stage research route across the canvas.

The route starts at a locked ruler and artifact bundle labeled “冻结基线”. It reaches a balanced twin-lane test gate labeled “Same-body 判决”. Only after that gate does it reach a compact one-layer dataflow island labeled “单层数据流”. The next stage expands from one layer to a few layers and is labeled “逐级扩大”. The final destination is not a trophy; show a neutral architecture map containing both a resident island and separate Graph/GEMM blocks.

At every early gate, draw a clear orange side branch ending in an archive folder grouped under “停止条件”. Keep those archived branches neat and valuable. The main route continues only when the preceding evidence gate is visibly open.

## Misleading claims to avoid

- Do not portray a whole-model Megakernel as the default or guaranteed destination.
- Do not skip the same-body architecture test.
- Do not turn an old latency target into a permanent universal threshold.
- Do not imply that increasing fusion scope is always progress.
- Do not portray a stop decision or negative evidence as wasted work.
- Do not add latency, per-layer savings, percentages, speedups, throughput, or any invented performance number.
