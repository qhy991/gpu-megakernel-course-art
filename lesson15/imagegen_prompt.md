# Lesson 15 ImageGen prompt

Purpose: create a beginner teaching image for a same-body experiment: Graph and Resident arms use identical mathematics and data contracts, while only the execution organization changes, making causal interpretation possible.

Use case: scientific-educational

Asset type: Lesson 15 hero infographic for a Chinese GPU course

## 16:9 visual requirements

- Exact canvas: 1672×941 pixels, landscape 16:9.
- Dark navy laboratory-blueprint background, cyan identical math modules, orange execution boundaries, lime correctness gate, violet paired timing.
- Crisp flat vector-like scientific comparison, perfectly symmetric twin tracks, generous whitespace, large readable Simplified Chinese typography.
- Module shapes, colors, order, inputs, and outputs must be visually identical on both tracks.
- No dense experiment card, code, photorealism, people, logos, watermark, result chart, or numerical measurement.

## Text (verbatim)

Main title:

“只改变组织方式，才能解释因果”

Short labels; render only these labels and no additional prose:

- “相同数学”
- “Graph 组织”
- “Resident 组织”
- “正确性门”
- “配对时延”

## Core composition

Draw two perfectly aligned horizontal experiment tracks fed by one shared input and ending at matching outputs.

Both tracks contain the same four abstract mathematical modules with identical shapes, colors, order, data arrows, and workspace trays. Group the identical modules under the label “相同数学”. On the upper track, place each module inside its own separate orange-outlined kernel chamber and connect the chambers as “Graph 组织”. On the lower track, place the same modules together inside one larger orange-outlined resident chamber labeled “Resident 组织”. Do not add or remove dataflow edges between the arms.

After both outputs, merge the tracks at one gate labeled “正确性门”. Only after that gate, route them into two alternating paired stopwatches labeled “配对时延”. Show small lock seals on layout, precision, tile ownership, input, and output icons so every variable except organization appears frozen. Use two small unlabeled shield icons to suggest a null control and a deliberately failing correctness control.

## Misleading claims to avoid

- Do not use different GEMM bodies, layouts, precision, reduction order, or mathematical operations between the two arms.
- Do not give the arms unequal input reset, host submission, or timing boundaries.
- Do not imply that winning the same-body comparison is already a production win.
- Do not skip the correctness gate, null noise control, or negative correctness control.
- Do not add fictional measurements, latency, percentages, speedups, pass counts, or a winner badge.
